These scripts parse the appendix to Executive Order -"Implementing Schedule Policy Career in the Excepted Service" from June 2026. The tables created in the first script, including independent federal agency and subagencies, position names, and position numbers. This dataframe is then joined to the raw OPM federal worker data, found here - https://data.opm.gov/explore-data/data/data-downloads to estimate how many employees are potentially impacted by this new requirement.
